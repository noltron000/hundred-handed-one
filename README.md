# The Hundred Handed One
This monster had a mass of 98 hands, and two very large ones.
So I had to script the effect that it had of having 100 attacks, naturally.
Its smaller hands were still large enough to wield a greatsword without using two hands.
A demon summoned this monster and outfitted it with weapons, which was pretty fun.

Anyway, this code is written in javascript and some html snippets.
I leveraged forms and popup prompts (hooked into foundry vtt) to determine how many attacks were being initiated, what the armor class was, how many hits were produced, and what the total damage would be.
